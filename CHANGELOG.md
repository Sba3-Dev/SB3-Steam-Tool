# Releases

## v0.0.1 — Initial UI foundation

- Added the SB3 Steam Tool application shell.
- Added a Welcome startup screen with separate update, Discord, Steam, and SB3 membership check rows.
- Added dedicated UI routes for Discord sign-in, Steam sign-in, and community membership.
- Added the main workspace sections: Overview, Library, Downloads, and Changelog.
- Added eight appearance themes and local theme preference.

> This is the initial frontend preview. Authentication, membership verification, automatic updates, and downloadable desktop builds are not yet connected.
